# Norns Programming Master Library

A comprehensive collection of resources for learning Monome Norns programming, including Lua scripting, SuperCollider engine development, and DSP fundamentals.

## 📁 Directory Structure

### 01-Documentation/
Core documentation organized by topic:
- **Norns/** - Official Norns documentation and guides
- **Lua/** - Programming in Lua chapters and reference
- **SuperCollider/** - SuperCollider tutorials and documentation  
- **DSP-Audio/** - Digital Signal Processing fundamentals

### 02-Tutorials/
*Ready for community tutorials and video content*

### 03-Examples/
Working code examples:
- **Norns-Scripts/** - Complete example Norns scripts
- **SuperCollider-Engines/** - Example engines with documentation

### 04-References/
Quick reference guides:
- **Lua-Quick-Reference.md** - Essential Lua syntax and patterns
- **SuperCollider-Quick-Reference.md** - SuperCollider for Norns development
- **Norns-API-Quick-Reference.md** - Complete Norns API reference

### 05-Learning-Resources/
Structured learning materials:
- **Norns-Learning-Roadmap.md** - 12-week progression plan
- **Practice-Exercises.md** - Hands-on coding exercises

### 06-Community-Resources/
*Space for community scripts, links, and collaborations*

## 🚀 Getting Started

### For Complete Beginners
1. Start with the **Norns Learning Roadmap** (05-Learning-Resources/)
2. Read **Programming in Lua Ch1-3** (01-Documentation/Lua/)
3. Work through the **Practice Exercises** (05-Learning-Resources/)

### For Experienced Programmers
1. Review the **Quick Reference Guides** (04-References/)
2. Study the **Example Scripts** (03-Examples/)
3. Jump to **SuperCollider documentation** (01-Documentation/SuperCollider/)

### For Norns Users New to Programming
1. Read the **DSP Fundamentals** (01-Documentation/DSP-Audio/)
2. Follow the **Learning Roadmap Phase 1-2**
3. Focus on **Lua fundamentals** before moving to SuperCollider

## 🎯 Learning Path

### Phase 1: Foundation (Weeks 1-2)
- Lua programming basics
- Norns hardware familiarity
- Simple script creation

### Phase 2: Norns Scripting (Weeks 3-4)  
- Parameter systems
- Screen drawing
- Clock and timing

### Phase 3: Advanced Scripting (Weeks 5-6)
- Grid integration
- Complex state management
- Community engagement

### Phase 4: SuperCollider Basics (Weeks 7-8)
- Audio synthesis fundamentals
- UGen programming
- Client-server architecture

### Phase 5: Engine Development (Weeks 9-10)
- Custom engine creation
- Polyphony and voice management
- Lua-SuperCollider integration

### Phase 6: Specialization (Weeks 11-12)
- Choose focus area (Grid, Sampling, Generative, Hardware)
- Build substantial projects
- Community contribution

## 🛠 Tools and Setup

### Required
- Monome Norns (hardware) or Norns Shield
- WiFi connection for Maiden access
- Basic understanding of file systems

### Recommended
- SuperCollider IDE (for engine development)
- Monome Grid (for grid programming)
- MIDI controller
- External audio interface

### Optional
- Code editor with Lua support
- Git for version control
- Audio analysis tools
