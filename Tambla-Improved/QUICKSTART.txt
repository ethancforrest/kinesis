FIRST TIME SETUP
----------------
1. LOAD the script from the Norns SELECT menu
2. CONNECT a MIDI keyboard to Norns
3. SET output device:
   - PARAMETERS > output > choose 'engine' or 'midi-1'
4. PRESS K3 to start the transport
5. HOLD a key on your MIDI keyboard - you'll hear rhythm!

TOOLTIPS:

BASIC WORKFLOW
--------------
1. START TRANSPORT: Press K3
2. TRIGGER PATTERNS: Hold MIDI keys
   - First key = Row 1 rhythm
   - Second key = Row 2 rhythm
   - Up to 4 simultaneous rhythmic voices
3. ADJUST PARAMETERS: Use encoders E1/E2/E3
   - Watch tooltips for real-time feedback
4. SWITCH PAGES: Press K2
   - PLAY page: Performance and row parameters
   - EDIT page: Individual step programming
   - MACRO page: Save/load patterns
5. GET HELP: Hold K1 on any page

UNDERSTANDING THE INTERFACE
---------------------------
PLAY PAGE (Main performance):
- E1: Select pattern slot (1-8)
- E2: Select row to edit (1-4) 
- E3: Adjust current parameter
- K3: Start/stop transport

EDIT PAGE (Step programming):
- E1: Select row (1-4)
- E2: Select step (1-16)
- E3: Adjust step value (velocity/chance/duration)
- K3: Toggle step on/off

MACRO PAGE (Pattern management):
- E1: Select slot
- E2: Choose operation (copy/save/load)
- E3: Navigate files/options
- K3: Execute action

KEY CONCEPTS
------------
ROWS: 4 independent rhythmic voices
- Each can have different length (2-16 steps)
- Each can have different timing (bend/offset)
- Triggered by holding MIDI keys

BEND: Timing curve for each row
- 1.0 = straight timing
- < 1.0 = fast start, slow end
- > 1.0 = slow start, fast end

STEPS: Individual triggers in each row
- Chance: Probability of playing (0-100%)
- Velocity: How loud (0-127)
- Duration: How long the note plays

TROUBLESHOOTING
---------------
NO SOUND:
- Check PARAMETERS > output setting
- Try 'engine' for internal audio
- Try 'midi-1' if using external synth
- Make sure transport is running (K3)

HELP NOT SHOWING:
- Hold K1 for full 1 second
- Must be on a valid page
- Release K1 to close

NO TOOLTIPS:
- Only appear when using encoders
- Last 2 seconds then disappear
- Some parameters don't have tooltips yet

MIDI NOT WORKING:
- Check SYSTEM > DEVICES > MIDI
- Reconnect MIDI device if needed
- Try different MIDI channels
